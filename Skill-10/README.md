# Academic Portal - Student Manager

A React application for managing students in an online academic portal. Add, display, and delete students dynamically without page refresh using React Hooks.

## Features

- Add new students with ID, name, and course
- Display list of all students in a table
- Delete students instantly with UI update
- Shows "No students available" when list is empty
- Clean and responsive UI with CSS styling
- Uses React Hooks (useState) for state management

## Installation

1. Clone the repository
2. Navigate to the project directory:
   ```
   cd Skill-10
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Running the Application

Start the development server:
```
npm start
```

The application will open in your browser at http://localhost:3000

## Building for Production

```
npm build
```

## Project Structure

- `src/StudentManager.js` - Main component with student management logic
- `src/StudentManager.css` - Component styling
- `src/App.js` - Root application component
- `src/index.js` - Application entry point
- `public/index.html` - HTML template
